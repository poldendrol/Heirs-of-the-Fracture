# Heirs of the Fracture

A bloodline of adventurers climbs the Endless Staircase across the countries of Vellorum, from the camp at Firststep, Kalandris.

The whole game is one file, `index.html`. Deployed on Render as a static site (`render.yaml`).

Online co-op and cloud saves only work when the game is opened as a claude.ai artifact; on Render it plays solo with saves kept in the browser.
